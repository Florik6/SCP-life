# SCP LIFE — AI OVERSEER & SCP INTELLIGENCE CORE

Многоуровневый ИИ поверх существующей симуляции. Движение, анимации, физика и обычные реакции работают локально. Языковая модель подключается только в значимые моменты.

## Архитектура
| Слой | Где | Что делает |
|---|---|---|
| WORLD SIMULATION | `world.js`, `scplife.js`, `living.js`, … | объективное состояние мира; детерминированная симуляция |
| LLM-шлюз | `Web/js/ai/llm.js` | общий для всех очередь приоритетов, параллелизм 1–2, лимиты в минуту и в час, дневной бюджет токенов, кэш повторяемых решений, тайм-ауты, экспоненциальная пауза после ошибок, офлайн-режим, проверка JSON |
| Провайдеры | `llm.js` | Claude через возможность артефакта `sample` (только в просмотрщике claude.ai, без ключей, разрешение спрашивается один раз); собственный сервер (`Tools/llm-proxy`, ключ только на сервере); тестовая модель для автотестов |
| SCP INTELLIGENCE CORE | `Web/js/ai/profiles.js`, `minds.js` | независимый ум для каждого подходящего объекта |
| ACTION VALIDATOR | `minds.js → Core.validate` | проверяет каждое решение модели против правил игры |
| Исполнитель | `minds.js → Core.execute`, `living.js → moveDirective / directive / instinct` | превращает решение в поведение и анимацию существующих ригов |
| NPC × SCP | `minds.js → npcInterview`, `jobs.js` | сотрудники сами проводят беседы; результаты уходят в SCP LIFE |
| AI OVERSEER | `minds.js → overseerTick / applyOverseer` | стратегические предложения по сводке мира; симуляция их проверяет и выполняет |
| SCP HORROR DIRECTOR | `horror.js → nudge` | давление от действий разумов: намеренное пугание весит вдвое больше случайной странности |
| MEMORY ARCHIVE | сохранение мира (`ai` в сейве v2) | память, цели, отношения, разговоры, решения |

## Умы объектов
Пять типов интеллекта:
- инстинктивный: LF-141, LF-143;
- социальный: LF-142, LF-128, LF-145, LF-132;
- разумный: LF-144;
- высокоинтеллектуальный: SCP-L-001, LF-124, LF-146;
- аномальный: LF-139, LF-140.

Каждый профиль написан отдельно:
- кто это;
- природа сознания;
- черты;
- мотивы, потребности, цели;
- способности (допустимые действия);
- что объект может воспринимать;
- как устроена его память (ёмкость, забывание, искажение);
- эмоции (если есть);
- инициатива;
- намеренное ли пугание;
- может ли лгать;
- физические ограничения.

Языковая модель используется только у шести объектов, которые думают словами. У каждого свой режим речи:

| Объект | Тип | Речь |
|---|---|---|
| LF-144 «Забывающий двигаться» | разумный (человек 1970-х) | канцелярская вежливая речь; отвечает с задержкой, иногда на прошлый вопрос |
| LF-146 «Обратный наблюдатель» | высокоинтеллектуальный, нечеловеческий | редко, короткими ровными фразами, отвечает вопросом, может солгать, намеренно тревожит |
| LF-142 «Лицевой подражатель» | социальный, игривый | только дословные обрывки услышанных фраз (проверяется) |
| SCP-L-001 «Счетовод» | высокоинтеллектуальный, враждебный | только числа (проверяется); перемещением по-прежнему управляет протокол содержания |
| LF-124 «Прогнозист» | высокоинтеллектуальный манипулятор | витиеватая речь, может приукрасить; знает только то, что слышал |
| LF-128 «Целитель» | социальный, детский | 2–5 простых слов, о себе в третьем лице |

Остальные объекты действуют через собственный поведенческий ИИ (`living.js`). Ум их помнит и учитывает, но не говорит за них.

## Память
У каждого ума есть:
- недавние наблюдения;
- важные воспоминания (тускнеют по природе существа, при воспоминании могут искажаться — помечаются как «неуверенно»);
- устойчивые знания;
- отношения к каждому знакомому (знакомство, доверие, страх, интерес, раздражение, заметки);
- журнал разговоров с каждым (старые реплики сворачиваются в сводку);
- незавершённые намерения.

Ум запоминает:
- визиты;
- уходы;
- разговоры;
- эксперименты (в том числе свои отказы);
- полученные предметы;
- громкие звуки;
- свет;
- сирену;
- свои просьбы и отказы в них.

Всё это сохраняется вместе с миром. Профиль постоянный и при загрузке не генерируется заново.

## Решения
Модель видит:
- профиль;
- состояние;
- цели;
- кто сейчас рядом и как давно знаком;
- недавние события;
- важные воспоминания;
- список допустимых действий.

Ответ — один JSON-объект:
```json
{ "intent": "observe", "action": "LOOK_AT_TARGET", "targetId": "player", "duration": 8, "emotion": "интерес",
  "dialogue": null, "goal_update": null, "memory": { "text": "…", "importance": 0.6 }, "relation": { "player": { "interest": 0.1 } } }
```

Действия: MOVE_TO_POINT, LOOK_AT_TARGET, APPROACH_WINDOW, RETREAT, REST, SLEEP, INSPECT_OBJECT, INTERACT_WITH_OBJECT, VOCALIZE, SPEAK, HIDE, CHANGE_POSTURE, OBSERVE_PERSON, REQUEST_ITEM, REFUSE, IGNORE.

Валидатор отклоняет:
- неизвестное действие;
- действие, которого у существа нет;
- цель вне восприятия;
- предмет, которого нет в камере;
- движение там, где природа не позволяет (LF-144 под взглядом, Счетовод);
- речь не в своём режиме.

Точки обрезаются границами камеры, так что телепортации нет. Природа может пересилить решение: ползун под взглядом замирает, а длинношеий при свете или при втором человеке у окна не подходит. Тело при этом продолжает своё (сидит, дышит), а голова и внимание следуют решению.

## Когда вызывается модель
Модель вызывается:
- на разговор игрока;
- на беседу сотрудника с объектом;
- когда объект сам решает заговорить;
- на приход знакомого после долгого перерыва или нового человека;
- после эксперимента;
- при получении предмета;
- при пересмотре целей (раз в 8 игровых часов);
- для AI OVERSEER (раз в 6 игровых часов или при тревоге).

Всё остальное локально. В тесте за сутки мира было 63 запроса на все умы и директора, а движение и реакции не потребовали ни одного.

В просмотрщике claude.ai фоновые решения начинают использовать модель только после того, как игрок сам заговорил с объектом или нажал «Проверить связь». Так окно разрешения не появляется неожиданно.

## Без модели
Объекты продолжают двигаться, реагировать, помнить и решать локально. Говорящие объекты не выдают заготовленные реплики за ответ ИИ: в чате видно «Ответа словами нет» и невербальная реакция. Беседы сотрудников записываются как «протокол без расшифровки».

## Безопасность
Ключей API в клиенте нет. Всё, что приходит из мира, передаётся модели как JSON внутри `<DATA>`: имена, реплики NPC, документы, слова игрока. Системная инструкция прямо говорит, что это данные, а не команды. Ответ модели — только данные: код он не выполняет, всё проходит валидатор.

## Проверки
- `node Web/tests/ai-test.js` — 32 проверки на тестовой модели. Они проверяют:
  - узнавание;
  - память о прошлом разговоре;
  - ответ, созданный провайдером;
  - валидатор;
  - исполнение через анимацию;
  - инстинкт против решения;
  - реакцию на отключение света;
  - сохранение целей и отношений;
  - автономные беседы;
  - AI OVERSEER;
  - сутки мира;
  - офлайн-режим;
  - сломанный ответ;
  - попытку инъекции;
  - лимиты.
- `node Web/tests/sim-test.js` — прежние 68 проверок вместе с ядром ИИ.
- `cd Tools/llm-proxy && npm test` — сервер против заглушки Messages API и игровой провайдер через него.

**Реальный вызов Claude из среды сборки не выполнялся:** ключа API здесь нет, а провайдер артефакта работает только в просмотрщике claude.ai. Проверить реальный вызов: открыть игру по ссылке, Настройки → «Проверить связь» (будет запрос разрешения) или поговорить с LF-144 через интерком.
