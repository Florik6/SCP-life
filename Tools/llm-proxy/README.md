# Сервер ИИ для SCP LIFE (APK и локальный браузер)

Ключ API нельзя класть в APK или в код страницы. Поэтому APK общается с языковой моделью через этот небольшой сервер: ключ хранится только на сервере, игроку выдаётся токен доступа, а сервер следит за лимитами и дневным бюджетом.

## Запуск
```bash
cd Tools/llm-proxy
npm install
ANTHROPIC_API_KEY=sk-ant-... SCP_PROXY_TOKENS=мой-длинный-токен npm start
# проверка: curl http://localhost:8787/health
```
Сервер слушает порт 8787 (`PORT`). Его можно развернуть на любом хостинге с Node.js 18+ и HTTPS.

## Настройки (переменные окружения)
| Переменная | По умолчанию | Что делает |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | ключ API (только на сервере) |
| `SCP_PROXY_TOKENS` | — | токены доступа через запятую; без них сервер не запустится |
| `SCP_MODEL` | `claude-opus-5-5` | модель для обычных запросов (диалоги, решения разумных объектов, AI OVERSEER) |
| `SCP_MODEL_QUICK` | как `SCP_MODEL` | модель для быстрых запросов; для экономии можно поставить `claude-haiku-5-5` |
| `SCP_PER_MINUTE`, `SCP_PER_DAY`, `SCP_DAILY_TOKENS` | 12, 600, 400000 | лимиты на один токен доступа |
| `SCP_ORIGINS` | `https://appassets.androidplatform.net,http://localhost:8000` | откуда разрешены запросы браузера |

Сервер использует официальный SDK `@anthropic-ai/sdk`. Глубину рассуждения задаёт `effort`: `low` для быстрых запросов, `medium` для обычных. Включён серверный резерв на случай отказа модели (`fallbacks: "default"`, бета `server-side-fallback-2026-07-01`). Если модель всё же отказала, игра получает пометку отказа и переходит на локальный ИИ: текст за модель не придумывается.

## В игре
Настройки → «Интеллект объектов» → указать адрес сервера (`https://…`) и токен, источник «СЕРВЕР ИИ» или «АВТО», затем «ПРОВЕРИТЬ СВЯЗЬ». Эта кнопка отправляет настоящий запрос и показывает ответ модели.

## Проверка без ключа
`npm test` запускает сервер против локальной заглушки Messages API и проверяет:
- токены доступа;
- что ключ подставляет только сервер;
- модель, effort и резерв;
- обработку отказа;
- лимит запросов;
- CORS;
- обмен с игровым провайдером из `Web/js/ai/llm.js`.

Реальный вызов модели этим тестом не проверяется: для него нужен настоящий ключ.
