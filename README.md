# SCP LIFE

Мобильная 3D-игра от первого лица (Unity, C#, URP) о живом, автономном подземном комплексе содержания аномалий. Комплекс живёт сам: охрана патрулирует, учёные проводят сеансы наблюдения, техник обходит щитки, заключённые класса D работают по распорядку. Катастрофа не заложена сценарием: опасность возникает из конкретных событий и ошибок.

**Текущее состояние: этап 1 (играбельный прототип).** Подробный отчёт: [Docs/STAGE1.md](Docs/STAGE1.md).

## Как открыть

1. Unity 6 LTS (6000.0.x, указана 6000.0.32f1) или новее. Код совместим с Unity 2022.3 LTS.
2. Откройте папку репозитория как проект через Unity Hub. Пакеты (URP, uGUI, Test Framework) подтянутся из `Packages/manifest.json`.
3. При первом открытии скрипт `ScpLifeProjectSetup` сам настроит проект. Вручную: меню **SCP LIFE → 1. Настроить проект**. Скрипт:
   - создаёт URP-ассеты для трёх уровней качества и назначает их уровням качества;
   - создаёт материалы-шаблоны в `Resources/ScpLife/Materials`, чтобы шейдерные варианты URP попали в сборку;
   - создаёт сцену `Assets/ScpLife/Scenes/Main.unity` и добавляет её в Build Settings;
   - настраивает Android: IL2CPP, ARM64, альбомная ориентация, Vulkan/GLES3, Linear.
4. Откройте `Main.unity` и нажмите **Play**. Подойдёт и пустая сцена: `GameBootstrap` создаётся автоматически.
5. Сборка APK: **SCP LIFE → 2. Собрать Android APK** (нужен установленный Android Build Support). Результат — `Builds/Android/SCPLife.apk`.

### Каталог аномалий

Файл `scp_life_120_original_anomalies.json` положите в `Assets/ScpLife/Resources/ScpLife/Data/`. Загрузчик (`AnomalyCatalog`) понимает массив записей или объект с массивом, распознаёт варианты имён полей на английском и русском и нормализует числовые характеристики (шкалы 0–1, 0–10 и 0–100). Записи видны во вкладке «Архив SCP» терминала. На этапе 1 поведение смоделировано только у SCP-L-001.

| Меню | ≡ | Esc / Tab |

## Структура

```
Assets/ScpLife/
  Scripts/Core/      симуляция на чистом C# без зависимостей от Unity (noEngineReferences)
    Common/          Vec3, детерминированный ГСЧ, игровые часы
    Data/            собственный JSON-парсер и сериализатор
    Facility/        помещения, двери, точки интереса, граф навигации, A*
    Access/          уровни L0–L5, разрешения, ключ-карты, журнал проходов
    Npc/             NPC: потребности, расписание, память, отношения, «мозг», диалоги
    Anomalies/       схема каталога, экземпляры, SCP-L-001 «Счетовод»
    Surveillance/    камеры, обзор, журнал фиксаций
    Simulation/      SimWorld (тик), события, тревога, задачи, диспетчер смены
    Content/         планировка сектора, персонал, камеры (этап 1)
    Save/            полное сохранение состояния мира
  Scripts/Runtime/   слой Unity: построение 3D, игрок, мобильный ввод, отображение NPC и аномалии,
                     CCTV, HUD, терминал, меню, процедурный звук, сохранение, производительность
  Scripts/Editor/    автонастройка проекта и сборка Android
  Tests/EditMode/    NUnit-тесты ядра (запускаются и в Unity Test Runner, и через dotnet test)
Tools/CoreTests/          проект dotnet test, компилирующий те же исходники ядра и тестов
Tools/UnityCompileCheck/  проверка компиляции Unity-слоя без редактора (по заглушкам API)
```

Ядро отделено от Unity: всё, что происходит в комплексе, считается в `SimWorld.Tick()` с фиксированным шагом 0,1 с. Unity только отображает состояние и передаёт ввод игрока. Поэтому удалённые сектора симулируются без отрисовки: помещения дальше трёх дверей от игрока обновляются раз в секунду. Логику можно тестировать без редактора.

## Проверка без Unity

```bash
cd Tools/CoreTests && dotnet test              # 42 теста ядра
cd Tools/UnityCompileCheck && dotnet build     # компиляция Runtime и Editor по заглушкам Unity API
```

Заглушки в `Tools/UnityCompileCheck/Stubs` написаны вручную и повторяют сигнатуры Unity 6. Они проверяют синтаксис и типы, но не заменяют компиляцию в Unity и запуск сцены.

## Ассеты

Сторонних моделей, текстур, звуков и шрифтов нет. Геометрия, персонажи и аномалия собраны из примитивов, текстуры генерируются кодом, звуки синтезируются, шрифт — встроенный в Unity.
